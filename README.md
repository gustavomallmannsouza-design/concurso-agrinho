# 🌾 Agro Forte, Futuro Sustentável

Projeto front-end desenvolvido para a **Subcategoria 3** do **Concurso Agrinho 2026**. O site aborda o tema obrigatório: *"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"*.

## 🚀 Objetivo do Tema
Demonstrar por meio de uma interface interativa como o setor agrícola pode expandir sua produtividade utilizando práticas que protegem a biodiversidade, economizam água e mitigam os impactos ecológicos.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estrutura semântica com formulários específicos.
* **CSS3**: Layout responsivo com suporte a inversão dinâmica de temas (Acessibilidade).
* **JavaScript**: Manipulação limpa de eventos e alteração dinâmica do DOM.

## 📁 Organização do Repositório
O código segue estritamente o critério de não utilizar estilos incorporados ou scripts inline nos arquivos HTML:
* `index.html` - Arquivo de marcação.
* `estilo.css` - Folha de estilo externa.
* `script.js` - Lógica de comportamento externa.
