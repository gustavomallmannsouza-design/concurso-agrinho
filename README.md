# Agro Forte, Futuro Sustentável - Concurso Agrinho 2026

## Objetivo do Projeto
Este website foi desenvolvido para participar do Concurso Agrinho 2026 na Categoria Programação (Subcategoria 3 - Ensino Médio). O principal propósito da página é conscientizar a comunidade sobre a importância da harmonia entre a produção agropecuária eficiente e a manutenção da sustentabilidade ecológica, trazendo dados relevantes e uma ferramenta interativa de diagnóstico.

## Tecnologias Utilizadas
* HTML5 (Estruturação Semântica)
* CSS3 (Layout Responsivo e Transições)
* JavaScript Vanilla (Manipulação Dinâmica do DOM)

## Instruções de Uso
1. Abra o arquivo `index.html` em qualquer navegador web moderno.
2. Utilize o menu superior para navegar suavemente pelas seções da página.
3. Clique no botão "Alternar Modo" para alternar o contraste visual entre o modo claro e o modo escuro.
4. Vá até a seção "Calculadora", insira seu nome, escolha uma prática agrícola no menu de seleção e clique em "Analisar Impacto" para visualizar um diagnóstico customizado diretamente na tela.
