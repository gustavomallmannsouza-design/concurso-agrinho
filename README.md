# 🚀 Projeto Web Base (HTML, CSS & JavaScript)

Este é um projeto web simples e estruturado, ideal como ponto de partida para o desenvolvimento de sites ou aplicações web. O projeto adota boas práticas de desenvolvimento front-end com uma arquitetura separada de arquivos.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização moderna utilizando variáveis, flexbox e suporte nativo a Modo Escuro.
* **JavaScript (ES6+)**: Interatividade, manipulação dinâmica do DOM e validação de dados.

## 📁 Estrutura de Arquivos

```text
├── index.html     # Página principal da aplicação
├── estilo.css     # Estilos e regras de design visual
└── script.js      # Comportamentos lógicos e interatividade
```

## ✨ Funcionalidades

* Layout totalmente responsivo para celulares e computadores.
* Adaptação automática ao Modo Escuro (Dark Mode) do sistema operacional.
* Validação de dados em tempo real no formulário.
* Manipulação dinâmica de elementos via JavaScript.

## 🚀 Como Executar o Projeto

Você não precisa instalar nenhuma dependência ou servidor pesado para rodar este projeto. Siga os passos abaixo:

1. Faça o download ou clone este repositório.
2. Certifique-se de que os arquivos `index.html`, `estilo.css` e `script.js` estão na mesma pasta.
3. Dê um duplo clique no arquivo **`index.html`** para abri--lo diretamente no seu navegador padrão.

---
💡 *Dica de Desenvolvimento: Se você usa o VS Code, instale a extensão **Live Server** para ver as alterações no código em tempo real diretamente no navegador.*
